## 0. Root cause found + FIXED this session (code)

**The dropped `task_comments` table was breaking every action button.**

`lib/orchestration/index.ts` still inserted into `public.task_comments` inside
`completeCard()` and `requestHelp()`. That table was dropped Day 51
(`drop_task_comments.sql`), so the insert errored and the function bailed out
*before* it could change the task's status. Result: the buttons looked dead.

Fixed by removing the dead breadcrumb writes (the `task_events` log already
records each action). Typecheck passes. **No SQL needed — this is a code change,
so it goes live on the next push to `main`.**
